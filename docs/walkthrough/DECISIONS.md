| D-15 | Which template version an inspection keeps when two devices could pin different ones (replaces D-12, which let an offline device's late, low-clock pin take over and break the PRD's "an inspection keeps the version it started on") | **server pin** at inspection creation; first pin by `(lamport, deviceId, opId)` wins (D-12); the inspector resolves conflicting pins on the device | **Decided by Shane 2026-11-14: server-issued pin at inspection creation; supersedes D-12.** `createInspection` (server only) writes the one `pin` op before any device op exists; devices get it when they download the inspection, and `localSet` refuses to write before then (`PinError('not-created')`).
